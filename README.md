# Flame World - It's game engine written by C++17.

It's game engine written by C++17.

![gameplay](video/gameplay.gif)

## Technologies
- C++17
- SDL3
- GLSL
- OpenGL 3.3
- Tinyobjloader
- OOP
- STL
- GLM

## Quick start
```bash
# Clone repo
git clone https://github.com/mental0-main/flame-world.git

# Move to direction
cd flame-world

# Build
clang++ -o flame-world ../src/*.cpp -lSDL3 -lGL -ltinyobjloader

# Run
./flame-world
```

## Controls
| Input | Action |
|-------|--------|
| WASD  | Movement |
| Mouse motion | Look around |
| Escape | Quit |
